# Sonora 

## Descripción

Sonora es una plataforma de streaming musical ficticia. Este proyecto consiste en desarrollar una aplicación de consola en C# para gestionar las suscripciones de sus clientes.

La aplicación está pensada para que un empleado pueda registrar nuevas contrataciones, gestionar los pagos y consultar un resumen de las ventas realizadas.

## Funcionalidades

- Registrar nuevas suscripciones.
- Seleccionar entre tres planes: Basic, Premium y Family.
- Añadir servicios adicionales a la suscripción.
- Elegir entre modalidad mensual y anual.
- Aplicar un descuento del 15 % en las contrataciones anuales.
- Calcular el importe total y gestionar el cobro.
- Mostrar un justificante de la contratación.
- Consultar estadísticas de las operaciones realizadas.

## Tecnologías utilizadas

- C#
- .NET
- Visual Studio

## Ejecución del programa

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `.csproj` con Visual Studio.
4. Ejecutar el programa.

También se puede ejecutar desde una terminal, situada en la carpeta del proyecto, mediante el comando:

dotnet run
